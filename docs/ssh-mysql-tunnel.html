从 Windows 安全连接 Alive 的 MySQL

这条命令在你的 Windows 电脑上运行，不是在腾讯云服务器中运行。

Windows 127.0.0.1:3307 → 加密 SSH 连接 → 服务器 127.0.0.1:3306 → MySQL

1. 打开 PowerShell

按 Win + R，输入 powershell，按回车。

2. 建立隧道

ssh -N -L 3307:127.0.0.1:3306 deploy@203.0.113.10

203.0.113.10 是文档示例地址，请替换为实际服务器地址。第一次连接输入 yes，然后输入对应 SSH 用户的密码。输入密码时屏幕不显示字符，这是正常的。

连接成功后窗口会一直空着。不要关闭它；关闭或按 Ctrl+C 就会断开隧道。

只有从 Windows 操作数据库时需要保持隧道。网站和服务器中的 Spring Boot 会直接连接 MySQL，不依赖这个 PowerShell 窗口。数据库客户端若支持 SSH，可以由客户端在每次连接时自动建立隧道。

3. 打开数据库客户端

主机：127.0.0.1
端口：3307
数据库：alive_game
用户名：alive_app
密码：服务器 .env 中的 MYSQL_PASSWORD

这里不能填写服务器公网 IP，因为数据库客户端连接的是 Windows 上刚建立的隧道入口。

4. 如果命令不可用

先运行 ssh -V。若提示找不到命令，需要在 Windows“可选功能”中安装“OpenSSH 客户端”。

参考：Microsoft OpenSSH 文档；OpenSSH ssh 手册。
