# Navicat 通过 SSH 隧道连接 MySQL

## 1. SSH 隧道是什么

SSH 隧道通过加密的 SSH 连接，把本地端口安全地转发到远程服务器上的目标端口。

在本项目中，MySQL 只监听服务器本机的 `127.0.0.1:3306`，不向公网开放。连接路径是：

```text
Windows
  → SSH（服务器公网 IP:22）
  → 云服务器
  → MySQL（127.0.0.1:3306）
```

连接过程包含两次身份验证：

| 身份验证 | 使用的账号 | 作用 |
| --- | --- | --- |
| SSH 登录 | 普通 Linux 部署用户 | 登录云服务器 |
| MySQL 登录 | `alive_app` | 登录 `alive_game` 数据库 |

因此，SSH 密码和 MySQL 密码不是同一个密码。使用 SSH 隧道后，无需向公网开放 MySQL 的 `3306` 端口；更换云服务商时仍然可以采用同样的方法。

## 2. 终端指令

在 Windows PowerShell 中执行：

```powershell
ssh -N -L 3307:127.0.0.1:3306 deploy@203.0.113.10
```

参数含义：

| 部分 | 含义 |
| --- | --- |
| `-N` | 只建立隧道，不进入服务器终端 |
| `-L` | 建立本地端口转发 |
| `3307` | Windows 本地端口 |
| `127.0.0.1:3306` | 从服务器内部访问的 MySQL 地址和端口 |
| `deploy@203.0.113.10` | 示例 SSH 用户和文档专用公网 IP；请替换为实际信息 |

第一次连接时输入 `yes`，然后输入该 SSH 用户的登录密码。密码输入时不会显示字符。

连接成功后 PowerShell 窗口会保持空白，需要让它一直运行。此时数据库客户端使用：

```text
主机：127.0.0.1
端口：3307
用户名：alive_app
密码：.env 中的 MYSQL_PASSWORD
数据库：alive_game
```

按 `Ctrl+C` 或关闭 PowerShell 会断开隧道。

## 3. Navicat 配置方法

Navicat 支持自动建立 SSH 隧道，因此使用 Navicat 时不需要先运行上面的 PowerShell 指令。

新建 MySQL 连接，在“常规”页面填写：

| 配置项 | 填写内容 |
| --- | --- |
| 连接名 | `Alive MySQL` |
| 主机 | `127.0.0.1` |
| 端口 | `3306` |
| 用户名 | `alive_app` |
| 密码 | `.env` 中的 `MYSQL_PASSWORD` |
| 初始数据库 | `alive_game`（如果有此项） |

切换到“SSH”页面，勾选“使用 SSH 隧道”，填写：

| 配置项 | 填写内容 |
| --- | --- |
| 主机 | `203.0.113.10`（示例地址，请替换） |
| 端口 | `22` |
| 用户名 | `deploy`（示例普通用户，请替换） |
| 验证方法 | 密码 |
| 密码 | 对应 SSH 用户的登录密码 |

点击“测试连接”，成功后保存。以后每次打开这个 Navicat 连接，它都会自动建立 SSH 隧道；关闭数据库连接后，隧道也会自动关闭。
